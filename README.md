# ゲームクラブ 出品スケジューラー

保存した下書きを、決めた時刻に自動で出品するツールです。Netlify上で24時間動くので、PCやスマホを起動しておく必要はありません。売れやすい時間帯の分析機能つき。

---

## はじめに知っておいてほしいこと

- **規約の確認はご自身で**:ゲームクラブの利用規約で「自動ツールでの出品」「同じ下書きの再出品」が許されているか、事前に確認してください。違反と判断されるとアカウント停止のリスクがあります。心配なら運営に問い合わせるのが確実です。
- **Cloudflareではじかれる可能性**:ゲームクラブはCloudflareを使っています。Netlifyのサーバーからのアクセスが拒否されると、このツールは動きません。これはゲームクラブ側の判断で、回避はしません。まず設定後の「接続テスト」で確かめてください。拒否された場合は使えません。
- **最初は「停止中」で始まります**:設定が終わるまで勝手に出品はされません。

## 導入手順(30分ほど)

### 1. ファイルをGitHubに置く

このフォルダ一式を、自分のGitHubリポジトリ(Private推奨)にアップロードします。GitHub DesktopにフォルダをドラッグしてCommit→Pushが簡単です。

### 2. Netlifyでサイトを作る

1. Netlify → Add new site → Import an existing project
2. 1で作ったリポジトリを選ぶ
3. 設定はそのままでDeploy

### 3. Blobs(データ保存)を有効にする

Netlifyのサイト → Integrations または Blobs の項目から有効化します。最近のNetlifyでは自動で有効なことが多いです。

### 4. パスワードを設定する（重要）

Site configuration → Environment variables → Add a variable

- Key: `ADMIN_PASSWORD`
- Value: 自分で決めた管理パスワード(他人に推測されにくいもの)

保存したら Deploys → Trigger deploy で再デプロイします。これを設定しないとサイトは動きません。

### 5. 開く

`https://あなたのサイト名.netlify.app` を開き、4で決めたパスワードでログインします。

## 使い方

### ① ログイン情報を登録(設定タブ)

1. PCのブラウザでゲームクラブを開く
2. F12 → Application → Cookies → https://gameclub.jp
3. `PHPSESSID` の Value をコピー
4. ツールの「設定」タブに貼り付けて保存
5. 「接続テスト」を押す → 「接続できました」が出ればOK

> ブラウザでログアウトすると無効になります。普段どおり放置していれば長期間有効です(期限は2030年)。

### ② 下書きを登録(下書きタブ)

1. ゲームクラブで対象の下書きを一度出品する(開発者ツールのNetworkを記録しながら)
2. `add?draft=番号` の通信 → Payload → 「View source」ボタン
3. 表示内容を全部コピー
4. ツールの「下書き」タブに、下書き番号とデータを貼り付けて追加

同じ手順を、出品したい下書きの数だけ繰り返します。並び順はドラッグで変えられ、上から順に出品されます。

### ③ 時間を決める(時間設定タブ)

「00:00〜24:00に15回」で約96分おきになります。時刻を1つずつ手動指定することも、分析結果から推奨時刻を入れることもできます。

### ④ 稼働開始(ホームタブ)

スイッチをオンにすると、予定時刻に自動出品が始まります。

## 分析機能

- 出品した時刻と、売れた時刻を記録して集計します。
- 「売れた」の記録は、分析タブの記録一覧で手動で印をつけるか、設定タブの「自動判定」をオンにします(出品ページの売り切れ表示を定期的に確認)。
- 時間帯×曜日のヒートマップと、売れやすい時間帯ランキングが見られます。データがたまるほど正確になります。

---

## 通知(任意)

設定タブにDiscordのWebhook URLを入れると、ログイン切れ・アクセス拒否・出品失敗のときに通知が届きます。

## よくあるトラブル

| 症状 | 対処 |
|------|------|
| ログインできない | ADMIN_PASSWORDを設定後、再デプロイしたか確認 |
| 「ログイン状態が切れました」 | 設定タブでPHPSESSIDを貼り直す |
| 「アクセスが拒否されました」 | CloudflareがNetlifyをはじいています。このツールは使えません |
| 自動実行が動いていない警告 | Netlify → Functions → tick のログを確認 |
| 出品が数分ずれる | 仕様です(サーバーは5分おきに動きます) |

---

## 技術的なしくみ(興味があれば)

- 出品は `POST /mypage/products/add?draft=番号` に、下書きのフォームデータを送るだけ。CSRFトークンは不要でした。
- 画像は下書き保存済みのものを番号指定で使うため、アップロード不要。
- ログイン判定は `PHPSESSID` クッキーのみ。ツールは自分でログインせず、あなたが取得したものを使います(Cloudflareの人間確認をすり抜けないため)。
- `netlify/functions/tick.mjs` が5分おきに動き、予定時刻を過ぎた枠があれば出品します。
